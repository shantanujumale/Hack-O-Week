📈 Regression Mathematics

This application executes predictions client-side using parameters extracted from the trained Linear Regression model with StandardScaler normalization.

1. Feature Scaling (Standardization)

Before making a prediction, the input features are standardized to have zero mean and unit variance using the parameters computed during training:

\[ z_i = \frac{x_i - \mu_i}{\sigma_i} \]

Where \(x_i\) is the raw input feature, \(\mu_i\) is the feature mean, and \(\sigma_i\) is the standard deviation scale.

2. Prediction Equation

The yield prediction \(\hat{y}\) is the dot product of the standardized feature vector \(\mathbf{z}\) and the regression coefficients weight vector \(\mathbf{w}\), shifted by the intercept \(b\):

\[ \hat{y} = b + \sum_{i=1}^{n} w_i z_i \]

This is equivalent to the matrix multiplication: \(\hat{y} = \mathbf{w}^T \mathbf{z} + b\).
